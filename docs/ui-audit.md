# Hush UI audit

Inventory of the production Go TUI. Paths in the table are relative to `tui/` unless otherwise noted. The anchor, dismissal, keys and styling columns describe the baseline; the last column tracks the migration. `ctrl+x` is the baseline leader. “Type to filter” includes Backspace and, for most pickers, paste; generic pickers use arrows, Home/End and Page Up/Down, and accept with Enter or Tab.
